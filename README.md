
# 📊 Pizza Sales Dashboard

## 🚀 Overview
This project presents an interactive **Pizza Sales Dashboard** built using SQL and Power BI. Raw sales data is processed using SQL queries and transformed into meaningful insights through Power BI visualizations.
The dashboard helps analyze sales performance, customer behavior, and product trends.

---

## 🎯 Objective
- Analyze overall sales performance  
- Identify best & worst-selling pizzas  
- Track daily and monthly order trends  
- Understand category and size contribution  
- Support data-driven decision-making  

---

## 💡 Solution
- Used **SQL** to extract, clean, and aggregate data  
- Built an interactive **Power BI dashboard** for visualization  
- Created KPIs and measures using **DAX**  
- Enabled filtering and drill-down for better insights  

---

## 🛠️ Tech Stack
- **SQL** – Data Extraction & Analysis  
- **Power BI** – Data Visualization  
- **Power Query** – Data Cleaning  
- **DAX** – Measures & Calculations  
- **Excel / CSV** – Data Source  

---

## 📂 Dataset
- Order Date & Time  
- Pizza Category  
- Pizza Size  
- Quantity Sold  
- Revenue  
- Order ID  

---

## 📈 Key KPIs
- **Total Revenue:** 817.86K  
- **Total Orders:** 21,350  
- **Total Pizzas Sold:** 49.57K  
- **Avg Orders per Day:** 38.31  
- **Avg Pizzas per Order:** 2.32  

---

## ✨ Features
- 📅 Date filter (Dynamic range)  
- 📊 Daily & Monthly sales trends  
- 🥇 Top 5 & Bottom 5 analysis  
- 🍕 Category-wise performance  
- 📦 Size-wise contribution  
- 🔍 Interactive dashboard
